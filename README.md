# CyberZone

Журнал о кибербезопасности простым языком — без страшилок и «взломай все» из фильмов.

## Что есть на сайте

- **Статьи** по основам цифровой безопасности (пароли, фишинг, 2FA, VPN, обновления).
- **Хакер-терминал** — интерактивная консоль с полезными инструментами защиты:
  - генератор стойких паролей с расчётом энтропии
  - шифровальщик текста (base64, hex, ROT13)
  - хеширование (SHA-256, MD5)
  - анализатор ссылок на признаки фишинга
  - проверка пароля на известные утечки (Have I Been Pwned)
  - чеклист цифровой гигиены

## Технологии

Чистые HTML / CSS / JavaScript, без внешних библиотек и серверной части. Все вычисления выполняются локально в браузере.

## Структура

```
cybersite/
├── index.html              # главная с поиском и статьями
├── hack-terminal.html      # интерактивный хакер-терминал
├── article-*.html          # статьи
├── css/style.css           # общие стили
└── js/
    ├── main.js             # поиск, навигация, фоновый эффект
    ├── sha256.js           # SHA-256
    └── md5.js              # MD5
```

> Материалы носят образовательный характер и не являются руководством к противоправным действиям.
