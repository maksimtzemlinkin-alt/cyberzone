# CyberZone

Журнал о кибербезопасности простым языком — без страшилок и «взломай все» из фильмов.

## О проекте

Учебный информационный сайт о цифровой безопасности. Тут рассказывается, как защитить свои данные, распознать обман и действовать безопасно в интернете — честно, без паники и мифов из кино.

На сайте:

- Статьи по основам безопасности: надёжные пароли, фишинг, двухфакторная аутентификация, VPN, фейковые сайты, обновления, защита от доксинга.
- Интерактивный «хакер-терминал» с полезными инструментами: генератор паролей, шифровальщик текста, хеширование, проверка ссылок и паролей, чеклист цифровой гигиены.
- Поиск по материалам.

## Стек

Сайт написан на чистом **HTML / CSS / JavaScript** и не использует внешних библиотек или серверной части. Все вычисления выполняются локально в браузере — данные никуда не отправляются.
